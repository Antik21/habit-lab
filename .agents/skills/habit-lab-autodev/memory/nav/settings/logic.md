# Settings logic

[`SettingsViewModel`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/settings/SettingsViewModel.kt) observes the theme preference, maps it through [`SettingsUiMapper`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/settings/SettingsUiMapper.kt), and delegates a selected theme to `SetThemePreference`. Its only navigation effect is `Back`. [`SettingsScreen`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/settings/SettingsScreen.kt) sends toolbar/theme UI actions through [`rememberNavigationActionDispatcher`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/navigation/NavigationActionDispatcher.kt), which admits them only while the entry is `RESUMED`.

[`AppNavigator.handleSettingsEffect`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/app/Navigation3AppHost.kt) accepts the emitted toolbar effect only while Settings is topmost, then returns to Gallery. Platform system/edge back is separate: [`Navigation3AppHost`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/app/Navigation3AppHost.kt) forwards it to `AppNavigator.onBack`, outside the UI-action gate.
