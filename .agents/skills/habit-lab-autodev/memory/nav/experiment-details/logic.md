# Experiment Details logic

[`ExperimentDetailsUiMapper.map`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/experimentdetails/ExperimentDetailsUiMapper.kt) keeps the route `ExperimentId` while mapping available, loading, and error content. [`ExperimentDetailsViewModel`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/presentation/experimentdetails/ExperimentDetailsViewModel.kt) pops to Gallery when its projection disappears.

The ViewModel permits edit only for a draft, obtains the local date before emitting `OpenDailyCheckIn`, and emits `OpenConfirmDelete` only for available content. A delete result with a different ID is ignored; confirmed delete (or loading during delivery) emits `PopToRoot`. [`AppNavigator.handleDetailsEffect`](../../../../../../shared/src/commonMain/kotlin/com/denis/habitlab/shared/app/Navigation3AppHost.kt) creates typed child routes. `resolveDelete` validates the immediate Details caller, then queues its typed result before snapshot persistence; the result is not serialized. Recomposition selects that queued delivery only for the matching Details route, passes it to the Details ViewModel, and consumes it by delivery ID.
